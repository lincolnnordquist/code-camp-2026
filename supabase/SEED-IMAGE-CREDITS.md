# Seed image credits

## Product photos: official merchandise images, demo use only

Every file under `seed-assets/products/` is an official merchandise or brand product photo from the brand's
own store or a licensed retailer's product page. They are used for the hackathon demo only and are
**not licensed for public or commercial use**. Replace them (for example with the Unsplash photos
kept in the attendee sandbox) before any use beyond the demo.

Each file is a tile image made from the original photo: the background was removed so the product
sits on the app's tile colour, then the product was trimmed, scaled so its longest side fills 78% of
the canvas, centred on 800 x 800 and saved as WebP (quality 82). `night-city-print.webp` and
`black-gold-dice-set.webp` are opaque square crops of the full scene instead.
